Caption an image How it works

The problem

Computers see pixels, people read sentences. The system must recognize what is in a picture and say it in grammatical English, for example "A dog is running in a grassy park."

Our approach

We use a pre-trained BLIP model as a working captioner, then train our own CNN + GRU captioner and measure how close it gets. No paid APIs are used.

What this page does

It is the front end for the project: upload an image, see both models' captions side by side, and review the evaluation results.

From pixels to words in five steps

The same pipeline runs for both models.

1

Input image

You upload a JPG, PNG, or WebP file.

2

Preprocessing

Pillow converts to RGB, then the image is resized and normalized.

3

Vision model

BLIP's vision transformer or ResNet-50 turns the image into features.

4

Language generation

The decoder writes the caption one word at a time with beam search.

5

Caption

Both captions appear side by side so you can compare them.

Limitations

  • BLIP saw far more training data, so it is a strong reference rather than a fair contest.
  • Our GRU is trained on 8,000 images and may give generic captions.
  • BLEU can penalize correct captions that use different words, so we also rate captions by hand.
