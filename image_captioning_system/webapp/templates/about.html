HARDWARE & LOCAL EXECUTION

Zero Cloud Dependencies

Unlike commercial web services that rely on paid cloud inference APIs, Caption Lens runs entirely on consumer workstation hardware:

  • Workstation GPU: NVIDIA GeForce RTX 4050 Laptop GPU (6GB VRAM)
  • Inference Runtimes: PyTorch 2.14.0 with CUDA 12.6 acceleration
  • Offline Model Checkpoint: Self-trained gru_best.pt (~27.6 MB)
  • No External API Fees: Fully reproducible open-source stack
RESPONSIBLE AI & DATA PRIVACY

Ethics, Privacy, and Dataset Bias

Vision-language models learn associative priors directly from human web annotations. The captions generated may occasionally inherit social, cultural, or geographic biases present in the Flickr8k training corpus.

Privacy Protection: All uploaded photos submitted through the demo console are held strictly in temporary RAM during the PyTorch forward pass and are discarded immediately upon response delivery. No user images are recorded to disk or collected.
